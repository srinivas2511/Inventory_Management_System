# wms/ CLAUDE.md

Warehouse Management System: zones, bins, transfer orders, wave picking, and cycle counts.

## Responsibilities
- `domain/` — `TransferOrder`, `TransferOrderLine`, `PickWave`, `PickWaveLine`, `CycleCount`, `CycleCountLine`.
- `service/` — bin-to-bin transfer (via `InventoryPostingService`); wave creation from approved sales orders; wave release and picking confirmation; cycle count execution and variance posting.
- `web/` — REST controllers: `/api/wms/**`; requires `WMS_VIEW` / `WMS_MANAGE` / `WAREHOUSE_MANAGER` role.

## Key design points (V27)
- **Transfer orders**: move stock between bins; each line is a separate `InventoryPostingService` call (out-leg from source bin, in-leg to destination bin).
- **Wave picking**: `GET /api/lookups/sales-orders/approved` feeds the wave creation dialog (approved SOs only). Wave lines are generated by grouping SO lines by warehouse zone.
- **Cycle counts**: count variance is posted as an inventory adjustment via `InventoryPostingService`; variances above the admin threshold require ADMIN approval.
- `WAREHOUSE_MANAGER` role holds all WMS permissions.
- WMS is currently **not plant-scoped** (deferred — see `docs/decisions.md`).

## IT coverage
- `WmsIT` (18 tests) — transfer order, wave creation/release/confirm, cycle count variance, permission checks.
