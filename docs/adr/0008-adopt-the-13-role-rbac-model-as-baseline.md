# ADR-08: Adopt the 13-role RBAC model as baseline

- **Status:** Accepted
- **Date:** 2026-10-01
- **Source:** ARCHITECTURE.md §20

## Decision
The detailed RBAC document supersedes the 7-role list in the system specification.

## Rationale
One authoritative, more precise role set.

## Alternatives rejected
Keeping both lists (ambiguous).
