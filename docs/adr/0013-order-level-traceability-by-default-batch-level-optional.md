# ADR-13: Order-level traceability by default, batch-level optional

- **Status:** Accepted
- **Date:** 2026-10-01
- **Source:** ARCHITECTURE.md §20

## Decision
Finished batches link to raw-material batches through the production order; exact sourcing optional per setting.

## Rationale
Meets the stated trace questions with low shop-floor data entry; precision available where needed.

## Alternatives rejected
Always batch-level (heavy data capture).
